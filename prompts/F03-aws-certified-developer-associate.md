# F03 – AWS Certified Developer Associate

Priorität C, Programmierung, Web & Design.

```text
Erstelle einen Lehrplan für den Kurs „AWS Certified Developer Associate“.

Fokus-Technologien / Plattformen: AWS-Entwicklung (Lambda, API Gateway, DynamoDB, SDKs, CI/CD), Zertifizierungsvorbereitung
Spezifische Vorkenntnisse: IT-Grundlagen und Grundkenntnisse in Programmierung
Umfang: etwa 12 Module (10 bis 14), zusammen etwa 100 bis 120 Unterrichtsstunden (UE)
Kernthemen: Developer-Associate Grundlagen und AWS Entwicklungsmodell; Development with AWS Services – Core Patterns; Serverless und Event-driven Applications; Datenzugriff, Persistenz und Caching; Security für Anwendungen; API Design und Integration Services; Deployment und CI/CD Workflows; Container und Application Packaging; Monitoring, Logging und Debugging; Troubleshooting und Optimization; Governance, Testing und Developer Productivity; Migration, BCDR und DVA-C02 Exam Readiness
Thematische Abgrenzung (Out of Scope): Keine Überschneidung mit vorhandenen Lehrplänen; Verweise auf vorhandene Lehrpläne nur kurz.
Spezifische Labor-Ressourcen: 1x Windows- oder Linux-VM mit Entwicklungsumgebung (Editor, Compiler bzw. Laufzeit); privater Hyper-V-Switch ohne Verbindung zum Heimnetz
Zusätzliche Hinweise: Versions-, Lizenz- und Supportstände mit Stand nennen; kennzeichne Unsicherheit; Menünamen und Befehle nicht erfinden. Prüfungsinhalte nach der aktuellen Prüfungsbeschreibung des Herstellers mit Stand nennen; keine Prüfungsfragen oder Prüfungsdumps wiedergeben.
```
