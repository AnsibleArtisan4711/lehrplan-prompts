# P57 – Azure-Netzwerk und Azure-Sicherheit

Priorität B, Azure und Identität.

```text
Erstelle einen Lehrplan für den Kurs „Azure-Netzwerk und Azure-Sicherheit“.

Fokus-Technologien / Plattformen: Microsoft Azure (VNet, NSG, Azure Firewall, Key Vault, Defender for Cloud), Azure CLI und PowerShell

Zusätzliche Hinweise: Versions-, Lizenz- und Supportstände mit Stand nennen; kennzeichne Unsicherheit; Menünamen und Befehle nicht erfinden. Preise und Gratis-Kontingente mit Stand nennen.
```
