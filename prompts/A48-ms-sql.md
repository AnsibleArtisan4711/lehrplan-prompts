# A48 – MS SQL

Priorität C, Datenbanken.

```text
Erstelle einen Lehrplan für den Kurs „MS SQL“.

Fokus-Technologien / Plattformen: Microsoft SQL Server (Installation, T-SQL, Sicherheit, Sicherung, Wartung, Performance), Windows Server
Spezifische Vorkenntnisse: IT-Grundlagen
Umfang: etwa 12 Module (10 bis 14), zusammen etwa 100 bis 120 Unterrichtsstunden (UE)
Kernthemen: MS SQL Grundlagen und Plattformarchitektur; Installation, Instanzdesign und Administrationstools; T-SQL Grundlagen und Datenmodellierung; Transaktionen, Locking und Row Versioning; Indexdesign und Query Performance; Security, Identity und Compliance; Backup, Restore und Recovery; High Availability und Disaster Recovery; Monitoring, Troubleshooting und Wartung; Integration, BI und Datenplattform; Automation, DevOps und Migration; Kosten, Skalierung, Governance und BCDR
Thematische Abgrenzung (Out of Scope): Teilweise abgedeckt durch bestehende Kurse oder Übungen: P32 SQL Server Administration; dort behandelte Inhalte nur kurz verweisen.
Spezifische Labor-Ressourcen: 1x Linux-Server-VM mit Datenbank; 1 Client-VM; privater Hyper-V-Switch ohne Verbindung zum Heimnetz
Zusätzliche Hinweise: Versions-, Lizenz- und Supportstände mit Stand nennen; kennzeichne Unsicherheit; Menünamen und Befehle nicht erfinden.
```
