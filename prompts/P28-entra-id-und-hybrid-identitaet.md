# P28 – Entra ID und Hybrid-Identität

Priorität B, Azure und Identität.

```text
Erstelle einen Lehrplan für den Kurs „Entra ID und Hybrid-Identität“.

Fokus-Technologien / Plattformen: Microsoft Entra ID, Entra Connect, Windows Server Active Directory
Spezifische Vorkenntnisse: IT-Grundlagen und Grundkenntnisse in Netzwerken (IP-Adressen, Subnetze); Active-Directory-Grundlagen
Umfang: etwa 12 Module (10 bis 14), zusammen etwa 100 bis 120 Unterrichtsstunden (UE)
Kernthemen: Entra-ID-Aufbau; Benutzer, Gruppen, Geräte; Entra Connect (Passwort-Hash-Synchronisation, Pass-through, Federation im Überblick); Hybrid Join; Mehrfaktor-Authentifizierung; Bedingter Zugriff (Lizenzabhängigkeit beachten); Privileged Identity Management im Überblick; Anwendungsregistrierungen; Troubleshooting und Diagnosewerkzeuge
Thematische Abgrenzung (Out of Scope): M365 Governance und Active Directory sind vorhandene Lehrpläne
Spezifische Labor-Ressourcen: 1x Domain Controller; 1 Client-VM; privater Hyper-V-Switch ohne Verbindung zum Heimnetz; zusätzlich Test-Tenant (Microsoft-365-Entwickler- oder Testzugang), kein produktiver Tenant, Laufzeit und mögliche Kosten vorab prüfen
Zusätzliche Hinweise: Lizenzabhängigkeiten (Free, Business, P1/P2) mit Stand nennen; Portalmenüs als „nicht bestätigt“ kennzeichnen, wenn nicht geprüft.
```
