# P25 – Docker und Docker Compose

Priorität B, Container.

```text
Erstelle einen Lehrplan für den Kurs „Docker und Docker Compose“.

Fokus-Technologien / Plattformen: Docker, Docker Compose, Debian/Ubuntu Linux
Spezifische Vorkenntnisse: IT-Grundlagen und Grundkenntnisse in Netzwerken (IP-Adressen, Subnetze); Linux-Grundlagen
Umfang: etwa 12 Module (10 bis 14), zusammen etwa 100 bis 120 Unterrichtsstunden (UE)
Kernthemen: Container und Images; Dockerfile; Registries; Volumes und Netzwerke; Docker Compose (Mehrcontainer-Anwendungen); Ressourcenlimits; Sicherheit (Rootless, Rechte, Images prüfen); Aufräumen; Logging; Sicherung von Daten; Troubleshooting und Diagnosewerkzeuge
Thematische Abgrenzung (Out of Scope): Keine Überschneidung mit vorhandenen Lehrplänen; Verweise auf vorhandene Lehrpläne nur kurz.
Spezifische Labor-Ressourcen: 1x Linux-Server-VM mit Docker; privater Hyper-V-Switch ohne Verbindung zum Heimnetz
Zusätzliche Hinweise: Lizenzbedingungen von Docker Desktop mit Stand nennen; als Alternative auf Docker Engine unter Linux eingehen.
```
