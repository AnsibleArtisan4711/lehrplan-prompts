# P24 – PowerShell Desired State Configuration (DSC)

Priorität B, Automatisierung.

```text
Erstelle einen Lehrplan für den Kurs „PowerShell Desired State Configuration (DSC)“.

Fokus-Technologien / Plattformen: PowerShell DSC, Windows Server
Spezifische Vorkenntnisse: IT-Grundlagen und Grundkenntnisse in Netzwerken (IP-Adressen, Subnetze); PowerShell-Kenntnisse
Umfang: etwa 12 Module (10 bis 14), zusammen etwa 100 bis 120 Unterrichtsstunden (UE)
Kernthemen: Konzept deklarativer Konfiguration; DSC-Konfigurationen und Ressourcen; Local Configuration Manager; Push und Pull; eigene Ressourcen; Prüfen auf Abweichungen; Einordnung gegenüber Ansible und Gruppenrichtlinien; Troubleshooting und Diagnosewerkzeuge
Thematische Abgrenzung (Out of Scope): Die PowerShell-Grundlagen stehen im vorhandenen Kurs „PowerShell“
Spezifische Labor-Ressourcen: 1x Windows-Server-VM (Pull-Server und Ziel); 1 weiterer Windows-Zielserver; privater Hyper-V-Switch ohne Verbindung zum Heimnetz
Zusätzliche Hinweise: Prüfe den aktuellen Stand der DSC-Versionen und ihre Zukunft mit Stand; kennzeichne Unsicherheit.
```
