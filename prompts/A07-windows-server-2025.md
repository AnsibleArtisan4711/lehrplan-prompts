# A07 – Windows Server 2025

Priorität C, Windows, Client & Betriebssysteme.

```text
Erstelle einen Lehrplan für den Kurs „Windows Server 2025“.

Fokus-Technologien / Plattformen: Windows Server 2025 (Installation, Rollen, Active Directory, Netzwerk, Sicherheit, Betrieb), PowerShell
```
