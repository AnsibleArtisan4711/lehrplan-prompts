# P22 – Infrastructure as Code mit Terraform

Priorität B, Automatisierung.

```text
Erstelle einen Lehrplan für den Kurs „Infrastructure as Code mit Terraform“.

Fokus-Technologien / Plattformen: Terraform, Hyper-V oder Proxmox bzw. lokaler Provider, Debian/Ubuntu Linux
Spezifische Vorkenntnisse: IT-Grundlagen und Grundkenntnisse in Netzwerken (IP-Adressen, Subnetze); Grundlagen einer Cloud- oder Virtualisierungsplattform
Umfang: etwa 12 Module (10 bis 14), zusammen etwa 100 bis 120 Unterrichtsstunden (UE)
Kernthemen: Konzept; Provider; Ressourcen und Datenquellen; Variablen und Ausgaben; State und Remote State; Module; Pläne prüfen und anwenden; Importieren; Zusammenspiel mit Ansible und cloud-init; Sicherheit der Zugangsdaten; Troubleshooting und Diagnosewerkzeuge
Thematische Abgrenzung (Out of Scope): Keine Überschneidung mit vorhandenen Lehrplänen; Verweise auf vorhandene Lehrpläne nur kurz.
Spezifische Labor-Ressourcen: 1 Arbeitsplatz-VM mit Terraform; 1 lokaler Virtualisierungshost als Ziel; privater Hyper-V-Switch ohne Verbindung zum Heimnetz; Cloud-Provider nur optional mit Test-Konto
Zusätzliche Hinweise: Prüfe Lizenzstand und Fork-Situation (Terraform und OpenTofu) mit Stand.
```
